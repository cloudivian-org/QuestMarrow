## How to contribute

1. **Open an issue first.** Describe the change (new level, bug fix, feature)
   and wait for a thumbs-up before doing significant work. This avoids wasted
   effort on changes that may not be accepted.
2. **Fork, branch, and open a pull request.** Keep PRs focused and small.
3. If you add or change a level, run the level checker and make sure it passes:
   ```bash
   node test.js
   ```
   Add a known-good solution for any new level to the `SOLUTIONS` map in
   `test.js`.
4. **Every pull request is reviewed and merged only with the maintainer's
   explicit approval.** Not every PR will be merged, and that's okay.
